Activer le copier-coller sur France Travail

Réactive le copier-coller sur les champs qui le bloquent (handler onpaste), notamment la page de changement de mot de passe. Blocage absurde à l'ère des gestionnaires de mots de passe autogénérés.

Installation (glisser-déposer) :

📋 Activer copier-coller

Comment installer le bouton ci-dessus :

  1. Affiche ta barre de favoris : Ctrl + Maj + B (Chrome, Edge, Firefox), Cmd + Maj + B sur Mac.
  2. Glisse le bouton bleu vers ta barre de favoris, puis relâche.
  3. Va sur la page France Travail où le collage est bloqué.
  4. Clique sur le favori. Un message vert confirme l'activation : tu peux coller dans tous les champs de la page.

Le glisser-déposer est la seule méthode fiable : Chrome ne permet pas d'ajouter un bookmarklet en téléchargeant un fichier.

Sinon, méthode console : ouvre la console (F12), colle le contenu de france-travail-enable-copy-paste.js, Entrée. Chrome refuse le premier collage dans la console : tape d'abord allow pasting puis Entrée.

Le bouton n'a pas pu être préparé : cette page doit être ouverte depuis GitHub Pages (ou un serveur local), pas en double-cliquant sur le fichier.
